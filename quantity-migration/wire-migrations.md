# Quantity and unit wire migrations

Canonical analysis scalar quantity objects keep their established canonical member names (`amperes`, `meters`, etc.). Constitutive/section fields that already encode canonical SI values as bare numbers keep those numeric wire shapes through the shared `canonical_scalar` serde adapter; the Rust fields are now semantic `Quantity<K>` values. Incoming non-finite values are rejected by the shared deserializer. No independent numeric/unit conversion table is introduced for those fields.

Source length declarations are represented by `LengthUnitEvidence`, distinct from a requested preview unit, retained kernel unit, or canonical solver unit. Unit definitions use checked dimension/scale/offset objects. Source attribution is not recovered from the requested coordinate scale.

Durable changes are versioned:

- `GeometryDocument`: schema 2 -> 3; canonical domain `analysis.geometry.document/v3`. Original declaration contexts and retained representation units replace the conflated source-unit/scale pair. Older documents require source reimport; they are not silently relabeled as meters.
- `GeometryAsset` preview interchange replaces `units` with optional role-typed `coordinate_units`; strict unknown-field decoding rejects old `units` payloads, requiring reimport. Unknown/unitless sources retain unscaled raw coordinates and an absent preview physical scale. Canonical source evidence and preview resolution must agree.
- `FigureScene`: schema 6 -> 7 adds optional geometry physical context. Legacy scenes can still render; physical measurements reject absent context rather than guessing a unit. A caller can no longer supply a measurement unit independently from the retained scene.
- `GeometryRevisionRef` now retains source-unit evidence, so portable canonical meshes, stage identities, and projections preserve the physical interpretation used to produce their canonical coordinates. Meshing identity schema 3 -> 4; solver mesh artifact 8 -> 9; solver projection 1 -> 2; meshing evidence 3 -> 4. Legacy physical artifacts must be rebuilt from their original source and explicit unitless fallback, rather than manufacturing missing provenance.
- Modal basis identity domain `runmat-fea-modal-basis/v1` -> `v2`: artifacts retain the full structural coordinate layout and checked one-kilogram mass reference. Generalized modal coordinates have length dimension; translational transform entries are ratios and rotational entries are radians per meter. Header-less legacy bases must be regenerated; no dimensionless modal-coordinate assumption is inserted.
- Structural intent continuation schema 1 -> 2 carries source-unit evidence independently from the canonical model. Its semantic digest includes that evidence; canonical meshing settings no longer accept a preview/source scale as an otherwise unused argument.

Canonical CBOR remains deterministic and domain separated. Geometry primary object payload versions are unchanged where their bytes and semantics did not change. Shared generated TypeScript contracts are generated from the Rust authority, including numeric serde adapters and the known length-unit catalog.

Pending audit: authored dimension/input/expression envelopes and remaining operation-envelope versions, preview cache invalidation, and any additional physical contract fields changed later in this migration must be recorded and tested before final integration. This document is not a completion assertion.

Legacy meshing `CadModel.unit_scale_to_m` is retired. Its coordinates are canonical typed positions, and its header now requires `CoordinateUnits<CanonicalCoordinates>`. Strict decoding rejects old unqualified scale payloads; source declaration/fallback evidence remains with the source geometry identity, independently of canonical coordinate storage.

- Modal resource estimation revision 109 → 110 includes the retained full physical DOF/node-set basis header once in payload/materialization admission. Arc sharing does not remove its storage cost.
- Recovered-field storage keeps its existing definition/identity wire shape; the existing ObservationQuantity/shape/association/complex representation header projects to the shared QuantityLayout. Host admission now rejects nonfinite numeric values. Generic descriptor-less diagnostic names are rejected at physical-field admission; modal and buckling scalar results remain separate procedure-specific contracts.
- Explicit structural topology identity still encodes canonical position IEEE bits under its established `coordinates_m` key; internal field renamed `coordinate_bits` to prevent treating bit representations as physical quantities. No identity byte reinterpretation.

- Physical scalar-system numerical carriers now retain a checked schema-1 state kind, free-equation descriptor, and mixed prescribed/free row layout; generic numerical AssembledRealSystem remains a mathematical storage contract. Thermal owner admission requires TemperatureDifference state and Power free equations. Electrical material normalization retains the actual derived free-row descriptor (Potential×Length), rather than claiming the scaled matrix is dimensionless.
- Electrical static result identity domain v1 → v2: potential/field arrays retain the canonical numeric array wire through shared storage adapters; outward flux and source/terminal work now carry the equation-derived shared descriptor (Charge vs Current, Energy vs Power). Admission verifies those kinds against the retained equation before execution/publication; old scalar-only wire payloads reject rather than silently acquire new units.
- LinearSolveResult gains a generic state storage parameter (default remains the existing raw numerical Vec). Typed physics exits reuse the same result/evidence implementation; thermal departure→absolute reconstruction explicitly changes Quantity kind. Diagnostic-only retained results use `()` after releasing state already materialized in snapshots.
- Electrical numerical receipt schema/domain v1 → v2 retains equation-derived units for total constitutive integral and net outward flux. Deserialization validates both shared descriptors against the receipt's retained electrical equation before identity/closure admission.

### Geometry expression units and signal phase

Geometry quantity source syntax is now retained as a `Quantity` expression node (source unit definition and original symbol) rather than a multiplication by an unlabelled scale. Resolved scalar values carry the shared dynamic descriptor. Legacy `Literal` graph nodes retain their established canonical SI interpretation only in an explicitly declared physical parameter or feature field; this compatibility rule never creates imported source-unit evidence. New source-authored quantity expressions are checked before canonical projection. Vector parameter declarations retain component descriptors. Affine transform translation slots 3, 7 and 11 are Length; the linear/homogeneous components are ratios.

Standard waveform time origin/duration, Hz frequency and angle phase now use shared static quantities with canonical numeric serde adapters, so existing canonical wire numbers retain their established meaning. Authored nonzero phase must have rad/deg; legacy bare zero remains zero-angle. Sine gain explicitly converts Frequency to AngularFrequency before multiplying Time.

Deserialize-only owners with handwritten serializers are compared against the migration baseline by `repair-canonical-wire-adapters`. Their original scalar/array fields use the same canonical adapters as derived serializers. Explicitly versioned dynamic-descriptor fields (for example electrical numerical receipts v2) are excluded: their new wire must retain dimensions and semantic kind, rather than silently erase the descriptor to the old number.

### Named signal axes and derivative frames

Named tabulated/generator/artifact domains retain `quantity: Option<DynamicDimension>`. Missing legacy metadata remains explicitly unresolved. Authored numeric input declarations resolve it during validation/realization; standalone execution rejects unresolved axes and requires `studyParameterWithUnits`. That overload describes canonical sampling coordinates and rejects noncanonical scale/offset rather than silently ignoring a conversion. Generic knot/sampling stencils remain mathematical storage, admitted under a checked shared Quantity axis view without copying coordinates. Signal-generator admissions now carry schema2 and a descriptor-bearing sample-point buffer; schema1/headerless admissions cannot execute. Materialization validates that buffer's descriptor against the authored domain.

Geometry derivatives use the shared `ParametricDerivative` envelope with a Quantity numerator and required parameter frames/orders. Known denominator units divide storage by their scale to the derivative order, retaining nominal angles. Native axes remain formal unresolved frames; they are never assigned meter or ratio dimensions. Geometry owner receipt/schema changes are coordinated with the root-owned exact-evaluator migration.

## Public exact evaluator receipts and definitions

Exact point/arc-length/curvature and projection IO now use the shared Position/Length/Curvature representation. Projection and pcurve receipts retain native or declared parameter coordinate frames; mixed UV components are separate formal coordinates and derivatives, never a fabricated uniform length/ratio. Native projection/pcurve payloads carry actual OCCT parameter tags and current kernel-coordinate scale. Native frame identifiers share Arc storage across receipt components. The existing registry v4 migration remains the admission boundary; source declared units remain independent from these evaluator-coordinate frames.

Portable definition/topology positions, control-point buffers and edge/vertex tolerances now retain shared quantities. Canonical serde adapters preserve established numeric wire shapes and reject nonfinite external values; they do not reinterpret old values under a new source unit. The checkpoint residual ledger explicitly distinguishes still-pending formal-basis and numerical-kernel reviews from completed physical owners.

### Spectral admission and shell coefficient roles

Numerical spectral-generator admission now requires schema 2 and a shared descriptor-bearing sample axis. Response-spectrum period coordinates retain Time; frequency and random-spectrum coordinates retain Frequency (Hz), without nominal radians. Old descriptor-less admissions reject rather than silently become a frequency axis. Materialization checks the exact authored axis and descriptor as well as generator identity. SpectrumAbscissa FrequencyHertz/PeriodSeconds now store shared Frequency/Time vectors; canonical-storage serde preserves their established array wire shape. Random-spectrum frequency-array follow-through remains in the explicit residual list.

Shell through-thickness inertia and proportional damping use separate const-generic roles with one shared QuantityField layout: coefficient order changes the length power and damping adds an inverse-time power. This is an internal representation change; the existing physical global M/C operator contracts and wire identities remain authoritative at assembly exit.
