# runmat-native-codegen

`runmat-native-codegen` owns RunMat's deterministic generic Native IR, its verifier, MIR lowering, ABI compatibility binding, liveness, and deterministic textual form. It consumes canonical MIR, `AnalysisStore`, executable manifests, shared facts/contracts, and the runtime-owned native ABI. It never performs private type or builtin inference.

Decoded IR must pass all three relevant checks: `NativeAssembly::verify` for structural invariants, `verify_against_manifest` for executable identity and requirements, and `verify_against_mir` for independent construct, local, binding, and canonical-name completeness. Target-specific cache keys bind the complete executable key to the Native IR schema and runtime ABI/layout. Region boundaries bind live values and guards to exact SSA/frame state, while conditionally embedded short-circuit constructs remain explicitly inventoried.

Cranelift lowering and relocatable object emission consume that same verified assembly. An object manifest binds the host target and ABI, optimization policy, executable/native cache keys, exact entrypoint and function symbols, emitted bytes, and bounded embedded runtime data by digest. ELF, Mach-O, and COFF are selected from the validated host target; unsupported or unprobed cross-target layouts fail before emission. Hotness, tiering, entry cells, provider placement, executable-memory lifecycle, link policy, and runtime language semantics remain outside this crate.

The selected AOT entry uses the stable `runmat_aot_entry` symbol, while every additional function retains a deterministic identity-derived symbol. Optional embedded data is canonicalized by symbol, limited in count and aggregate size, and emitted through Cranelift's object module rather than platform-specific byte patching. The backend produces a relocatable user object only; it does not discover linkers, own a runtime archive, write output paths, or define artifact-distribution policy.

On native targets, generic Cranelift lowering compiles the verified Native IR block graph directly. Generated entrypoints use the runtime-owned ABI and identify semantic work with a typed, path-independent site request; a host adapter maps that identity back to immutable Native IR and shared runtime operations. Generated code does not embed MIR payload layouts, runtime `Value` storage, or an executor-private tagged value ABI. Web/WASM keeps the same verified Native IR product and does not compile host-native Cranelift modules.

Generated entrypoints dispatch through the exact runtime-owned resume block instead of assuming every entry begins at the function entry block. Invalid function/block resume identities fail closed before a semantic site executes. Position, phase, and ordinal remain explicit in the resume record for host-side exact-site continuation, exception transfer, and deoptimization; Native IR remains the authority that proves those sites exist.

Native IR function metadata retains every ordered MIR local together with its local kind and optional semantic binding identity/name. Bound locals must have a canonical HIR-derived name at lowering time. The verifier rejects incomplete metadata, so workspace, global, persistent, and workspace-first name resolution never depends on executor-specific VM slots. Native IR also retains the shared semantic default and validation contract for each fixed input, keyed by exact native local identity; decoded artifacts are checked both structurally and against canonical MIR before execution. Native IR schema version 2 introduced the serialized local catalog, and schema version 4 added the argument-validation catalog.

Schema version 3 adds verified output-local identities and a self-contained catalog of context-dependent scalar/range indexing expressions. Lowering derives this catalog from uniquely defined MIR temporaries; structural verification checks local references and expression shape, while canonical-MIR verification rejects omission or substitution. Hosts can defer those recipe temporaries and resolve `end` exactly once against the selected base shape without recovering provenance from placeholder values or bytecode.
