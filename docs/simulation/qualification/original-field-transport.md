# Original field inputs across portable structural studies

Standalone structural roots use schema 4. Their required source inventory binds
original field references to canonical field manifests, payload identities and
prepared input resource facts. Numerical values travel through the shared
partitioned field transport; they are not embedded in root metadata.

The submitter resolves the complete captured model source union from one shared
artifact-store snapshot with a cumulative allowance. The allowance honors every
authored step ceiling. Preparation profiles original values, partition encoding
and shared transport construction before numerical copies. Worker decoding checks
inventory and budgets, imports the closed object graph, independently rederives
resource facts and validates the original bindings. Missing, duplicate, extra,
substituted and understated sources fail closed. Access rebinding changes transport
authority without changing the original values or source identity.

Local composition, remote composition and client result validation use the same
field-aware analysis planner after actual geometry and meshing. Field topology,
quantity, frame and activation remain governed by shared model/workload admission.
Workers require no submitter runtime store. The result expectation retains the
complete original bindings; metadata hashes alone do not authorize reconstruction
or establish a mathematical proof.

## Evidence and boundaries

The native Tet4/Tet10 fixture uses actual solved original displacement and velocity
fields to check portable preparation, cold decoding, exact payload preservation,
access rebinding and inventory/budget rejection. Its existing cold transient block
witness checks partition equivalence. Portable closure testing does not execute
an authored CAD consumer with those fixture fields.

A separate runtime process witness publishes an actual solved original field to
the shared filesystem artifact store, waits for the producer process to terminate,
and starts a fresh consumer. Only reference metadata and an expected original-value
digest are exchanged outside the store. The consumer recovers the original field,
deduplicates selection and rejects foreign references and a one-byte allowance.
This establishes shared-store source survival, not full authored native CAD reuse
or arbitrary transient-history restart.

Resource bounds are analytical admission budgets. No measured RSS, distributed
solve, accelerator capability or release qualification follows from these tests.
All existing scientific accuracy gates and authored limits remain unchanged.
