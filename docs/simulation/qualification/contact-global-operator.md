# Prepared global contact operator and original configuration

This is a source-bound global contact assembly component. It does not
advance the body Newton solver, authorize continuation or enable public contact execution.
The nonlinear preparation route still rejects contact until its complete admission,
state, solve, accuracy and publication chain is qualified.

## Prepared source and physical scope

`CanonicalContactOperator` borrows one canonical projection, the original authored
interfaces and the shared caller-supplied translational row map. It owns compiled
reference inventories, prepared point scopes and the shared potential sparse pattern.
It creates no self-referential structure and copies no mesh or interface model into
point bindings. Prepared point scopes are encoded once. Live point binding checks the
same immutable borrowed source authorities and uses no codec/allocation; pointer
addresses are never encoded into a portable physical scope.

Per-interface controls explicitly select penalty law, search/range/separation,
stationarity/metric/feature limits and admissible initial penetration. There are no
inferred penalty constants. Unknown nested serialized controls reject. Selection
counts are bounded before index allocation; original reference-point and all-pair
coupling limits precede physical trial work. Duplicate secondary laws and conflicting
primary/secondary roles across interfaces reject. Shared primary surfaces remain
possible; no face transition is credited as history transfer.

Physical configuration identity binds original projection, complete ordered authored
interfaces, row map and numerical controls. Pure operator resource caps bind a distinct
execution identity. Increasing a resource ceiling does not change physical-state
identity; the fresh execution plan must still rederive and satisfy the new caps.
These hashes identify scope and provenance, not past-trajectory or equilibrium proofs.

## Original global configuration and immutable trials

`ContactConfigurationState` owns original full nodal positions once, an external
ordinal and ordered compact original point records. Each record retains scope,
primary face/material coordinates, original frame/relative vector and every traction,
inelastic slip, accumulated sliding and friction-work component. It stores no repeated
primary/secondary face-coordinate arrays. Local coordinates are obtained from the
retained original full configuration, not solved again or recovered from field means.
Present-state validation checks complete scope/ordinal/order/geometry/frame/law; it
does not establish that a historical trajectory occurred.

Each trial receives immutable original configuration and current nodal positions.
A current surface index is built once per interface and point pairing uses bounded
shared distance search plus stationary refinement. A changed primary face, ambiguous
pair, unsupported feature, exhausted work/storage, invalid history or cancellation
returns an error and no partial output. Every point trial uses the same original
configuration. Only the owning body procedure may accept a candidate after all its
convergence and mandatory accuracy gates pass.

Residual and full smooth-branch tangent scatter through the shared planned assembler.
The matrix is general: friction and geometric terms are not advertised as SPD. The
reference measure gives nominal penalty traction, not current-area Cauchy traction.
Diagnostics retain normal/tangential elastic energy, Coulomb work, algorithmic elastic
loss and separation release separately. Numerical losses are not frictional heat.

## Requested storage and bounded work

Resource components describe exact requested prepared/trial payload and conservative
construction/transient peaks using actual types, canonical codec profiles and shared
surface-search storage. Construction includes selection/quadrature/support/union,
point-scope and operator/execution identity work. Trial output includes complete
positions/point records, residual and planned matrix capacity; transient search is
additional. Borrowed mesh/model/row-map inputs, committed configurations, the body
operator/solver, retained history/output, transport, allocator overhead and measured
RSS remain additional. This is not whole-task memory or performance qualification.
Patch work is bounded across the entire trial. Refinement counts are conservative
geometry-evaluation bounds, not measured CPU work. Cancellation rejects before initial
allocation and within prepared/search/point work.
